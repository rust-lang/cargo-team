- josh: Vibe check: hint-mostly-unused
    - Thinking of an MCP to add a flag to rustc to provide a way to do best-effort code-gen as much as possible. Essentially "inline yes". This can avoid codegen for crates where there is a lot of unused code.
    - Possibly add a cargo profile, a way to set this for specific packages.
    - mir-only rlib ran into corner cases, and may never be stabilized. https://github.com/rust-lang/rust/pull/119017
    - This would be more stabilizable than the experiment "inline yes" threshold.
