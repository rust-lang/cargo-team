## new rustc lint `misleading_cfg_in_build_script`

* https://github.com/rust-lang/rust/pull/153721#discussion_r2920072597
* This lint checks for usage of `#[cfg]`/`#[cfg_attr]`/`cfg!()` in `build.rs`.
* The current implementation is not desired that it inspects the crate name `build_script_build` to determine whether it is compiling `build.rs`.
* Urgau's proposal: rustc provides an allowed-by-default lint, and Cargo can opt-in it when building build scripts.
* Do we want it? Should we have a Cargo lint as a frontend of this rustc lint?
